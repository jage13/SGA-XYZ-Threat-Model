# SGA XYZ - Threat Modeling

## Descripción
Modelado de amenazas del Sistema de Gestión Académica XYZ,
desarrollado como parte de una actividad académica de
Seguridad en Aplicaciones.

## Objetivo
Identificar, evaluar y priorizar amenazas de seguridad
mediante la metodología STRIDE.

## Herramientas
- OWASP Threat Dragon
- STRIDE
- Diagramas de Flujo de Datos (DFD)
- Git y GitHub

## Diagramas
- Nivel 0: Contexto general del sistema.
- Nivel 1: Arquitectura interna.
- Nivel 2: Módulo de reportes académicos.

## Resultados
- 18 amenazas identificadas.
- 10 hallazgos prioritarios.
- 8 casos de abuso.
- 8 controles de seguridad propuestos.
- Evaluación del riesgo residual proyectado.
- Roadmap de remediación.

## Versionado
Versión inicial: v1.0

## Alcance
Los resultados corresponden a un ejercicio académico
de modelado de amenazas. No representan vulnerabilidades
técnicamente comprobadas.
